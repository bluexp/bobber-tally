BobberTally

无限钓鱼助手

每次收竿都有记录。看清这一趟钓了什么，按拍卖行挂单或 NPC 售价估算收获。

下载插件 ZIP 查看 GitHub 源码 ↗

v0.7.0 · 客户端接口 16001 · 简体中文与英文

抛竿、记账、查鱼

钓鱼工具栏

点击鱼钩抛竿，点击装备图标换装。柱状图打开渔获统计，齿轮打开钓鱼设置。用最右侧的四向箭头拖动工具栏。

抛竿统计与渔获估价

查看本次渔获、用时和每小时估价。直接在拍卖行「购买」页刷新报价并查看查询进度。

鱼类与烹饪资料库

查阅 88 条鱼类记录和 24 条烹饪配方。点击参考钓点打开游戏地图，也可查看角色实际钓获的地点与数量。

统一钓鱼设置

在一个窗口管理快捷键、水花声、交互键、自动拾取和鱼漂搜索。换装向导与钓鱼操作可随时切换。

安装与设置

  1. 解压插件

    下载 ZIP，把解压出的 WowfFishing 文件夹放入 _forever_/Interface/AddOns/。

  2. 启用插件

    重启游戏，在角色选择画面启用「无限钓鱼助手」。进入游戏后输入 /wowfish。

  3. 配置换装

    输入 /wowfish setup，选择鱼竿和要换回的武器，再录入换装键。向导会等游戏确认装备后继续。保存时请关闭装备管理器。

  4. 设置抛竿键

    打开「钓鱼设置」，录入抛竿 / 收竿键并开启「交互键」。录入鼠标侧键时，把鼠标停在按钮上再按侧键。按一次抛竿，听见水花声后再按一次收竿。

游戏内命令

/wowfish
打开统计与渔获面板
/wowfish setup
打开换装配置向导
/wowfish gear
查看换装方案和最近一次结果
/wowfish settings
打开统一钓鱼设置
/wowfish loot
打开同一钓鱼面板
/wowfish fish
打开鱼类资料库
/wowfish about
打开关于窗口
/wowfish lang zh|en|auto
选择中文、英文或跟随客户端，再用 /reload 应用

使用边界

免费、源码可查的玩家自制插件。抛竿与收竿均由玩家按键触发。拍卖行报价是查询时的挂单估值。设置、报价和实钓记录保存在本地游戏设置中。
