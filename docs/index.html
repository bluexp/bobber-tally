抛竿、记账、查鱼

钓鱼工具栏

点击鱼钩抛竿，点击装备图标一键换装，点击三条横杠打开钓鱼面板。用最右侧的四向箭头拖动工具栏。

抛竿统计与渔获估价

在同一窗口查看抛竿次数、渔获数量和两种总价。打开拍卖行后可手动刷新报价，本次无渔获时可查询资料库里的鱼类和成品。

鱼类与烹饪资料库

查阅 88 条鱼类记录和 24 条烹饪配方。点击参考钓点打开游戏地图，也可查看角色实际钓获的地点与数量。

安装与设置

  1. 解压插件

    下载 ZIP，把解压出的 WowfFishing 文件夹放入 _forever_/Interface/AddOns/。

  2. 启用插件

    重启游戏，在角色选择画面启用「无限钓鱼助手」。进入游戏后输入 /wowfish。

  3. 配置换装

    输入 /wowfish setup，按提示选择鱼竿、装备要换回的武器，再装备所选鱼竿并保存快捷键。保存时请关闭装备管理器。

  4. 设置抛竿键

    在渔获面板点击「设置抛竿 / 收竿键」并按下空闲键。也可输入 /wowfish bind G，G 可换。在游戏设置开启交互键后，抛竿和收竿分别按一下。

游戏内命令

/wowfish
打开统计与渔获面板
/wowfish setup
打开换装配置向导
/wowfish loot
打开同一钓鱼面板
/wowfish fish
打开鱼类资料库
/wowfish about
打开关于窗口

使用边界

免费、源码可查的玩家自制插件。抛竿与收竿均由玩家按键触发。拍卖行报价是查询时的挂单估值。设置、报价和实钓记录保存在本地游戏设置中。
