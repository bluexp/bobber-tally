# 为 BobberTally 贡献 / Contributing to BobberTally

提交前请阅读 [LICENSE](LICENSE)、[NOTICE](NOTICE) 和[许可问答](addons/WowfFishing/LICENSING.md)。本项目采用自定义的非商业使用及署名许可 1.0，属于源码可用项目。

- 你保留自己贡献的版权。明确提交用于并入本项目的原创补丁，按同一许可 1.0 提供；这不是版权转让，也不授予维护者另行商业使用你贡献的权利。不同安排须在提交前取得明确书面约定。
- 仅提交你有权许可的内容。引用第三方源码或数据时，在提交说明中列出作者、原始链接、版本、具体引用范围和完整许可，保留必要署名。没有明确许可的公开源码不能仅凭“已致谢”认定可复制或再许可。
- 说明改动目的、影响和验证结果；修改版保留原项目来源。不要提交账号、游戏角色存档、凭据或其他私人数据。
- 本仓库接收 BobberTally 插件源码、插件说明、许可、版本记录及插件打包工具。官网、论坛、客户端、小红书工具和素材走各自维护渠道。
- Issue 中的反馈不会自动转让版权；若提交可并入的原创补丁，请明确确认许可。维护者不能替第三方作者授权。

建议在 PR 描述中写明：

> 我有权提交本补丁的原创内容，并按 BobberTally 非商业使用及署名许可协议 1.0 提供用于并入项目。第三方引用及许可已完整列明。
